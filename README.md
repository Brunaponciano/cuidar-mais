# ❤️ CUIDAR+
### Seu cuidado, organizado em um só lugar.

## 💡 Sobre o projeto

O CUIDAR+ é um projeto que estou desenvolvendo na disciplina de **Projeto Integrador da minha faculdade**, durante minha jornada de aprendizado em Análise e Desenvolvimento de Sistemas.

Como trabalho na área da saúde, tenho contato com pacientes e observo algumas dificuldades que fazem parte da rotina deles. Uma situação que me chama a atenção é o esquecimento de horários de medicamentos e de consultas agendadas.

Pensando nesse problema real, tive a ideia de desenvolver o CUIDAR+, uma aplicação que busca ajudar na organização dessas informações e facilitar o acompanhamento da rotina de cuidados com a saúde.

Este projeto também é uma oportunidade de colocar em prática os conhecimentos que estou adquirindo na faculdade, aprender novas habilidades e entender como a tecnologia pode ser utilizada para ajudar a resolver problemas do dia a dia.

📚 **Status:** versão inicial funcional. O projeto continua em desenvolvimento.

## 🎯 Objetivo

Desenvolver uma aplicação simples que ajude a organizar informações sobre medicamentos, registrar doses tomadas e acompanhar consultas.

A ideia é começar com funcionalidades básicas e evoluir o projeto aos poucos, conforme meu aprendizado e as necessidades identificadas.

**Importante:** o CUIDAR+ é um projeto acadêmico em desenvolvimento. Ele não substitui orientações de profissionais de saúde nem garante que o paciente se lembre de tomar seus medicamentos ou comparecer às consultas.

## ✨ Funcionalidades implementadas

### 💊 Medicamentos
- Cadastrar medicamentos.
- Listar medicamentos cadastrados.
- Editar informações dos medicamentos.
- Excluir medicamentos.
- Registrar doses tomadas.
- Consultar o histórico de doses registradas.

### 🩺 Consultas
- Cadastrar consultas com nome, data, horário e local.
- Visualizar consultas cadastradas em ordem cronológica.

### 💾 Armazenamento de dados
- Salvar informações em arquivos JSON.
- Carregar os dados salvos quando o programa é iniciado.

## 🛠️ Tecnologias utilizadas

- **Python 3:** linguagem utilizada para desenvolver o programa.
- **JSON:** formato utilizado para armazenar os dados localmente.
- **Git:** ferramenta utilizada para controlar as versões do código.
- **GitHub:** plataforma utilizada para publicar o código e acompanhar a evolução do projeto.

## ▶️ Como executar o projeto

### Pré-requisitos
- Python 3 instalado no computador.
- Git instalado, caso queira clonar o repositório.

### 1. Clonar o repositório

```bash
git clone https://github.com/Brunaponciano/cuidar-mais.git
```

### 2. Entrar na pasta do projeto

```bash
cd cuidar-mais
```

### 3. Executar o programa

```bash
python main.py
```

No Windows, dependendo da instalação do Python, também pode ser necessário utilizar:

```bash
py main.py
```

## 📁 Armazenamento dos dados

O programa utiliza os arquivos `medicamentos.json` e `consultas.json` para armazenar as informações cadastradas localmente.

Esses arquivos são utilizados para que os dados possam ser carregados novamente quando o programa for iniciado.

Os arquivos estão incluídos no `.gitignore` para evitar que os registros locais sejam enviados ao GitHub por engano.
